TimeTracker

Pointage d'heures de travail en Markdown → bilan hebdomadaire et mensuel, en Markdown et en PDF.

Télécharger la dernière version Voir le code source

Ce que ça fait

  • Un seul fichier texte à éditer : releve.md, un tableau Markdown avec arrivée, pause déjeuner et départ.
  • Règle de pause minimale configurable — une pause de 15 min compte quand même pour 30 min si c'est le minimum réglé.
  • Jours d'absence (Congés, Maladie, Férié, RTT, Divers) neutres sur le solde d'heures.
  • Bilan hebdomadaire et mensuel, avec report du solde d'un mois sur l'autre et alerte de tolérance.
  • Rapport Markdown et PDF mis en forme, générés en une commande.
  • Binaire natif autonome : aucune installation de runtime nécessaire.

Aperçu

---
duree_journee: 8h12
pause_minimum: 0h30
---
|Date      |Arrivée|Début pause|Fin pause|Départ|Absence|
|----------|-------|-----------|---------|------|-------|
|28.09.2026|8h50   |12h00      |12h20    |16h50 |       |
|29.09.2026|       |           |         |      |Congés |
$ TimeTracker
Bilan genere : bilan.md
Bilan PDF genere : bilan.pdf
