# Politique de sécurité

## Versions supportées

TimeTracker n'a pas de branches de maintenance : seule la dernière release publiée est supportée.

## Signaler une vulnérabilité

Merci de **ne pas** ouvrir d'issue publique pour un problème de sécurité potentiel.

Utilisez plutôt l'onglet [Security → Report a vulnerability](https://github.com/ymauray/timetracker/security/advisories/new) de ce dépôt (signalement privé GitHub). Vous recevrez une réponse dans les meilleurs délais, et le correctif sera publié avant toute divulgation publique.
